# AI-Augmented SDLC — Assignment 1

This repository contains both parts of the AI-Augmented Software Development Life Cycle assignment.

## Part 1A — SpendWise Personal Expense Tracker

A personal expense tracking application developed using GitHub Spec Kit and an AI-augmented development workflow.

**Technologies:** FastAPI, SQLite, React, TypeScript, Vite.

[View Part 1A](./Part-1A/README.md)

## Part 1B — Natural-Language Reminder Agent

An AI-powered reminder agent that interprets natural-language reminder requests and determines whether to create, reschedule, or clarify a reminder.

**Technologies:** FastAPI, Python, Pydantic, Gemini API, React, Vite.

[View Part 1B](./Part-1B/README.md)
